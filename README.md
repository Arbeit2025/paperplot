# 論文プロット（paperplot）

論文・レポートの「プロット」（構成・アウトライン）を組み立てる小さなツールです。創作用ツール [plotbox](https://github.com/Arbeit2025/plotbox) の論文版という位置づけで、論文タイプのテンプレートに沿って入力すると、章ごとの「書くことガイド」付きアウトラインを Markdown で生成します。

## 使い方

1. **論文タイプ**を選ぶ（卒業論文（標準型）／比較・整理型／実践・開発報告型／レポート型）。
2. テーマ、研究問い（RQ）、仮説・主張、先行研究メモ、対象・データ、方法、結果の要点、考察で言いたいこと、意義・貢献を、分かる項目だけ入力する。
3. **🧩 アウトラインを作る**を押すと、章・節の見出しと「この節で書くこと」のガイド、入力内容を流し込んだアウトラインが Markdown で表示される。
4. **📋 コピー**でそのまま文書に貼る、**⬇ ダウンロード**で `.md` ファイルとして保存できる。

空の項目は「（未入力）」として残るので、これから調べる・考える項目の目印になります。入力内容はサーバーに保存されません。同じ入力からは常に同じアウトラインが生成されます。

## 技術構成

Python / Flask の単一ファイル構成（app.py）。テンプレートは app.py 内に保持し、生成は決定的に行います。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
pip install pytest
python -m pytest tests/
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。
